# Лабораторная работа №3 — метеоданные шести городов

Двухэтапный пайплайн: **классификация типа климата** по окну дневного временного ряда и **прогноз среднесуточной температуры на 30 дней** для каждого города (отдельные модели), затем **объединение в единый сценарий инференса**.

## Подготовка данных

1. Поместите архив `data.zip` в каталог `lr3/` (рядом с ноутбуком).
2. Распакуйте его так, чтобы появилась структура `lr3/data/данные/*.parquet` (или любая вложенность под `data/`, скрипт ищет все `*.parquet` рекурсивно).

Пример в PowerShell из папки `lr3`:

```powershell
Expand-Archive -Path data.zip -DestinationPath data -Force
```

## Окружение

Рекомендуется виртуальное окружение Python 3.10+.

```powershell
cd lr3
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
jupyter notebook main.ipynb
```

Либо в VS Code / Cursor: откройте `main.ipynb` и выполните ячейки сверху вниз. Полный прогон обучает несколько лесов и регрессоров на всех городах и может занять несколько минут.

## Интерпретация результатов

- **Раздел 2.1–2.2:** EDA, стационарность (ADF), корреляции, признаки (лаги, скользящие, климатическая норма, PCA).
- **Классификация:** метрики accuracy / precision / recall / F1 (macro и weighted), матрица ошибок, ROC-AUC OvR, важность признаков (permutation importance), точность по сезону окна.
- **Прогноз:** для каждого города на тесте (2025) выводятся MAE, RMSE, MAPE, WAPE и доля верно угаданного направления изменения между соседними днями горизонта; графики факт vs прогноз; boxplot ошибок; проверки остатков (Шапиро, Льюнг-Бокс, Уайт).
- **Двухэтапный класс `TwoStageWeatherPipeline`:** на вход подаётся **не менее 30 последних дневных** наблюдений с колонками как в исходных parquet + инженерные поля из ноутбука. Если известен город, передайте `city="..."`, чтобы не полагаться на эвристику выбора города внутри климатической зоны.
